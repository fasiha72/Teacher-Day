# 💌 Teacher's Day – Secret Letter of Gratitude

A creative and interactive **Teacher's Day tribute webpage** made with **HTML & CSS only**. 🌸

This project is designed as a heartfelt digital letter for teachers, featuring beautiful blessings, inspirational quotes, elegant animations, and a special interactive **"Open My Heart"** experience.

## ✨ Features

* 💌 Interactive gratitude letter
* ❤️ CSS-only open/close interaction
* 🌸 Beautiful teacher blessings
* 💖 Inspirational quotes
* ✨ Animated floating particles
* 🎀 Elegant card design
* 💫 Smooth CSS animations
* 📱 Fully responsive design
* 🚫 No JavaScript required

## 🛠️ Technologies

* HTML5
* CSS3
* CSS Animations
* CSS Transitions
* CSS Flexbox
* Responsive Design
* CSS Checkbox Interaction

## 🎨 Project Concept

The project is designed around a **Secret Letter of Gratitude**.

The visitor first sees a beautiful letter card with an **"Open My Heart"** button. Clicking the button reveals heartfelt blessings, respectful messages, inspirational quotes, and a personal thank-you message for teachers.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Click **"Open My Heart"**.
5. Enjoy the Teacher's Day experience. 💌
